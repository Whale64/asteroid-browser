# Asteroid Browser
A simple mobile web browser built with MIT app inventor.

### Installation
Right now, the only way to download this app is using the .apk file in the releases section of this github repo. I might put it on the play store but it is unlikely.

### Support
| OS           | Version        |
| ------------ | -------------- |
| Android      | 6.0 or later   |

### Features
| Features                 |
| ------------------------ |
| Page Reloading           |
| < and > keys             |
| Home page with shortcuts |
| URL bar and page titles  |
| All modern web languages |
| Google Search            | 

## Enjoy!
